# PSiptv 1.7.5 — Android e Windows

- Capas dos podcasts na pesquisa aberta pela TV ao Vivo e na lista de podcasts favoritos.
- Podcasts ordenados pelo número de episódios por ouvir, com os que têm mais episódios pendentes primeiro.
- Contagens respeitam o perfil ativo e atualizam-se com alterações de consumo e sincronização.
- Carregamento das contagens em grupos de quatro pedidos, com utilização da cache quando a rede falha.
- Ordem estável nos empates e preservação dos restantes conteúdos nos favoritos mistos.
- Alternativa para capas de pesquisa quando o diretório de podcasts não fornece a imagem de maior resolução.

## Pacotes

- Android: `PSiptv.v1.7.5.apk`, assinado com a mesma identidade da versão anterior e com versionCode superior.
- Windows x64: `PSiptv.v1.7.5.windows-x64.zip`, distribuição autónoma com o atualizador pela web.

No Windows, use a página de atualizações ou extraia o ZIP para uma pasta com permissões de escrita e execute `PSiptv.exe`. Na primeira instalação do atualizador, é necessário extrair o ZIP manualmente. Num repositório privado, configure um token GitHub com acesso Contents: Read.
