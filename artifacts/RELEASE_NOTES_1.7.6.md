# PSiptv 1.7.6 — Android e Windows

- Canais favoritos ordenados do mais recentemente aberto para o mais antigo, com atualização ao mudar de canal.
- Canais sem histórico aparecem no fim, por ordem alfabética. A ordenação respeita a lista e o perfil ativos.
- Barra vertical de canais em ecrã inteiro no design Clean passa a abrir à direita, junto dos botões de controlo.
- Os restantes designs mantêm a barra horizontal no topo.

## Pacotes

- Android: `PSiptv.v1.7.6.apk`, assinado com a mesma identidade da versão anterior e com versionCode superior.
- Windows x64: `PSiptv.v1.7.6.windows-x64.zip`, distribuição autónoma com o atualizador pela web.

No Windows, use a página de atualizações ou extraia o ZIP para uma pasta com permissões de escrita e execute `PSiptv.exe`. Na primeira instalação do atualizador, é necessário extrair o ZIP manualmente. Num repositório privado, configure um token GitHub com acesso Contents: Read.
